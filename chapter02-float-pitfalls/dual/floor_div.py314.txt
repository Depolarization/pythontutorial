== -7 // 2 == -4：floor（向负无穷）语义 ==
FD -7 // 2 -> -4
MD -7 % 2 -> 1
FD 7 // 2 -> 3
MD 7 % 2 -> 1
FD 7 // -2 -> -4
MD 7 % -2 -> -1
FD -7 // -2 -> 3
MD -7 % -2 -> -1
DM divmod(-7, 2) -> (-4, 1)
DM divmod(7, -2) -> (-4, -1)
MD 规律 -> 余数符号永远跟除数 b；商 = floor(a/b) 向负无穷取整
== 与 C/Java 相反：那边是截断（trunc），余数符号跟被除数 ==
C trunc(-7/2) -> -3
C C/Java 的 -7/2 -> -3（Python 给 -4）
C C/Java 的 -7%2 -> -1（符号跟被除数；Python 给 1）
C C/Java 的 7%-2 -> 1（Python 给 -1，同为负但归属相反）
C Python 的 int() 才是截断：int(-3.7) -> -3；-3.7 // 1 -> -4.0
== float 也是同一套 floor 语义 ==
FL -7.0 // 2 -> -4.0
FL -7.5 % 2 -> 0.5
FL -0.1 % 1 -> 0.9
FL 5.5 % -2 -> -0.5
== divmod 恒等式：(a//b)*b + a%b == a，10 万随机正负数 ==
ID int    组数 -> 100000
ID int    不成立数 -> 0
ID int    全量成立 -> True
ID int    耗时 -> 0.135 s
ID float  组数 -> 100000
ID float  不成立数 -> 11（int 恒等式有保证；float 是近似，极端比值下差 1 个 ulp）
ID float  耗时 -> 0.060 s
