== Decimal(str) vs Decimal(float) ==
DV Decimal('0.1') -> 0.1
DV Decimal(0.1)   -> 0.1000000000000000055511151231257827021181583404541015625
DV 两者相等 -> False（一个是你以为的 0.1，一个是 float 0.1 的精确真值）
DV Decimal('0.1')+Decimal('0.2') -> 0.3
DV 和等于 Decimal('0.3') -> True
DV Decimal(0.1)+Decimal(0.2) -> 0.3000000000000000166533453694
DV 和等于 Decimal(0.3) -> False（喂进去的是二进制近似值，Decimal 也救不回来）
== Decimal 的除法在上下文精度内会舍入 ==
DV 上下文精度 -> 28 位
DV Decimal(1)/Decimal(3) -> 0.3333333333333333333333333333
DV (1/3)*3 -> 0.9999999999999999999999999999（差万分之一，不是 1）
== Fraction：精确有理数，分子分母都是任意精度整数 ==
FR Fraction('0.1') -> 1/10
FR Fraction(0.1) -> 3602879701896397/36028797018963968（float 输入的精确二进制展开）
FR Fraction(1,3)*3 == 1 -> True
FR Fraction('0.1')+Fraction('0.2') == Fraction('0.3') -> True
FR Fraction(0.1)+Fraction(0.2) == Fraction(0.3) -> False（输入是 float，一样救不回）
FR Fraction(1,10)+Fraction(2,10) -> 3/10（自动约分）
FR float(Fraction(1,3)) -> 0.3333333333333333（输出时才转 float）
== 一句话选型 ==
PICK 记账/金额 -> Decimal(str) 或整数分；需要分数运算（配比/利率） -> Fraction
PICK 统计/科学计算 -> 直接 float，比较用 math.isclose
