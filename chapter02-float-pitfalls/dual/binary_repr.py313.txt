== 为什么存不下 0.1：0.1 的二进制是无限循环小数 ==
BIN 0.1 的二进制前 28 位 -> 0.0001100110011001100110011001…
FRAC float(0.1) 的精确分数 -> 3602879701896397/36028797018963968
FRAC 分母 -> 2 的 55 次方（double 一律是 k/2^e，没有 1/10 这种分数）

== 正确比较：math.isclose ==
IC (0.1+0.2)==0.3 -> False
IC isclose(0.1+0.2, 0.3) -> True
IC 默认 rel_tol -> 1e-09（容差随量级放大）
IC isclose(1e10, 1e10+1) -> True（差 1，但容差是 10）
IC isclose(1e-9, 0.0) -> False（rel_tol 对 0 失效）
IC isclose(1e-9, 0.0, abs_tol=1e-8) -> True（比 0 必须给 abs_tol）
